# Часто задаваемые вопросы (FAQ)

## 🚀 Установка

### Q: На каких операционных системах работает скрипт?
A: Скрипт поддерживает:
- Ubuntu 20.04, 22.04, 24.04
- Debian 11, 12
- CentOS Stream 8, 9
- RHEL 8, 9
- Rocky Linux 8, 9
- Fedora 35+

### Q: Сколько времени занимает установка?
A: Обычно 5-15 минут, в зависимости от скорости интернета и производительности сервера.

### Q: Какую панель выбрать - 3x-ui или Marzban?
A: 
- **3x-ui** - проще в настройке, подходит для начинающих
- **Marzban** - больше функций, API, поддержка множественных узлов

## 🔧 Настройка

### Q: Какие порты использует скрипт?
A: По умолчанию:
- 443 - VLESS Reality
- 2053 - VMess WebSocket / 3x-ui панель  
- 8000 - Marzban панель
- 8388 - Shadowsocks

### Q: Как изменить пароли по умолчанию?
A: После установки:
- Войдите в веб-панель
- Перейдите в настройки аутентификации
- Смените логин и пароль

## 🌐 Протоколы

### Q: Какой протокол самый быстрый?
A: **VLESS + XTLS-Reality** обеспечивает максимальную скорость и наименьшую задержку.

### Q: Что такое WebSocket и когда его использовать?
A: WebSocket позволяет проксировать трафик через CDN (например, Cloudflare), что полезно для обхода блокировок.

## 🛠 Устранение неполадок

### Q: Панель управления не открывается
A: Проверьте:
```bash
systemctl status x-ui        # для 3x-ui
systemctl status marzban     # для Marzban
ss -tlnp | grep :2053        # проверка портов
```

### Q: Как посмотреть логи?
A: 
```bash
# Логи 3x-ui
journalctl -u x-ui -f

# Логи Marzban  
marzban logs
```
