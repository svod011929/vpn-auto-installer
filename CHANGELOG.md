# Changelog

Все значительные изменения в этом проекте будут документированы в этом файле.

## [1.0.0] - 2025-10-16

### Добавлено
- Автоматическая установка панелей 3x-ui и Marzban
- Генератор оптимальных конфигураций для VLESS, VMess, Shadowsocks
- Системная оптимизация (BBR, network tuning)
- Автоматическая настройка firewall
- Скрипт обслуживания и мониторинга
- Docker Compose конфигурация
- Полная документация на русском языке
- Поддержка Ubuntu, Debian, CentOS, RHEL, Fedora

### Протоколы
- **VLESS + XTLS-Reality**: Максимальная скорость и безопасность
- **VMess + WebSocket**: Универсальная совместимость
- **Shadowsocks/Outline**: Простота и стабильность

### Особенности
- Одна команда для полной установки
- Предустановленные оптимальные конфигурации
- Автоматическое создание трех инбаундов
- Система мониторинга и отчетов
- Безопасные настройки по умолчанию
